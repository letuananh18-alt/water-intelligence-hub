⚡ Cấu hình Cổng Supabase Realtime AI Gateway (Kết nối n8n qua CSDL)

Khi bật tính năng này, tất cả câu hỏi trên AI Assistant sẽ được tự động chèn vào bảng Supabase ai_chat_requests. Node n8n của anh sẽ đọc từ Supabase, cho AI trả lời và Update a row. Hệ thống sẽ tự động lắng nghe Postgres Realtime và hiển thị câu trả lời ngay lập tức (Không sợ bị chặn CORS!):

Kích hoạt chế độ AI Gateway qua Supabase Realtime + n8n Engine
📜 Xem đoạn mã SQL Mở Quyền Ghi (Tắt RLS) cho bảng 'ai_chat_requests' trên Supabase 
-- 1. Tắt RLS để bảng ai_chat_requests chuyển thành UNRESTRICTED (Giống tất cả các bảng khác trong dự án của anh)
ALTER TABLE public.ai_chat_requests DISABLE ROW LEVEL SECURITY;

-- 2. Đảm bảo Kích hoạt tính năng PostgreSQL Realtime cho bảng
ALTER PUBLICATION supabase_realtime ADD TABLE public.ai_chat_requests;
